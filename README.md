# Provoware Präzisions-Agent – Profi-Dateipaket

Dieses Paket enthält eine optimierte Agenten- und Codex-Arbeitsgrundlage für robuste Tool-Entwicklung, GUI-Optimierung, Validierung, Performance, Dokumentation und proaktive Qualitätsverbesserung.

## Inhalt

| Datei | Zweck |
|---|---|
| `AGENTS.md` | Hauptregelwerk für Codex, ChatGPT und Entwicklungsagenten |
| `CODEX_KURZPROMPT.md` | Kompakter Auftragsprompt für konkrete Repo-Aufgaben |
| `MASTER_PROMPT_TOOLENTWICKLUNG.md` | Umfangreiche Profi-Version für neue Tool-Projekte |
| `GUI_UX_STANDARD.md` | Moderne GUI-, Dashboard-, Barrierefreiheits- und Layout-Regeln |
| `PERFORMANCE_EFFIZIENZ_STANDARD.md` | Regeln für Geschwindigkeit, Ressourcenschonung und Code-Sparsamkeit |
| `VALIDIERUNG_QA_STANDARD.md` | Prüfpflichten, Teststrategie, Qualitäts-Gates und Fehleranalyse |
| `PROJEKTSTRUKTUR_TEMPLATE.md` | empfohlene Ordner-, Datei- und Modulstruktur |
| `CHECKLISTE_ABSCHLUSS.md` | Abschluss- und Übergabecheckliste |
| `TESTPROTOKOLL_TEMPLATE.md` | Vorlage für Testnachweise |
| `CHANGELOG_TEMPLATE.md` | Vorlage für dokumentierte Änderungen |

## Empfohlene Nutzung

1. Lege `AGENTS.md` in das Hauptverzeichnis deines Repositorys.
2. Nutze `CODEX_KURZPROMPT.md` für konkrete Codex-Aufträge.
3. Nutze `MASTER_PROMPT_TOOLENTWICKLUNG.md` für neue Tools oder große Umbauten.
4. Prüfe nach jedem größeren Schritt mit `VALIDIERUNG_QA_STANDARD.md`.
5. Verwende `GUI_UX_STANDARD.md`, wenn moderne Oberfläche, Dashboard oder Bedienlogik betroffen sind.
6. Führe vor Abschluss `CHECKLISTE_ABSCHLUSS.md` durch.

## Kernziel

Ein Entwicklungsagent soll nicht wild programmieren, sondern kontrolliert arbeiten:

- erst analysieren
- dann planen
- dann minimal sinnvoll umsetzen
- dann prüfen
- dann dokumentieren
- dann proaktiv verbessern

## Priorität

Qualität, Stabilität, Bedienbarkeit und Wartbarkeit haben Vorrang vor reiner Funktionsmenge.
Geschwindigkeit bedeutet nicht hastige Umsetzung, sondern effiziente Architektur, schlanke Logik, klare Datenwege und schnelle Bedienung.
