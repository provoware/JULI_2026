# Abschlusscheckliste

Vor Abgabe eines Tools oder einer größeren Änderung müssen diese Punkte geprüft werden.

## 1. Zielerfüllung

- [ ] Aufgabe verstanden
- [ ] Hauptziel umgesetzt
- [ ] Nebenanforderungen berücksichtigt
- [ ] keine unnötigen Zusatzfunktionen eingebaut
- [ ] bekannte Grenzen benannt

## 2. Codequalität

- [ ] Syntax geprüft
- [ ] Imports geprüft
- [ ] keine undefinierten Variablen
- [ ] keine abgeschnittenen Funktionen
- [ ] keine Platzhalter
- [ ] keine unnötigen Dopplungen
- [ ] Funktionen sind verständlich benannt
- [ ] Code ist modular
- [ ] Kommentare erklären sinnvolle Stellen

## 3. Stabilität

- [ ] Fehlerbehandlung vorhanden
- [ ] ungültige Eingaben abgefangen
- [ ] fehlende Dateien abgefangen
- [ ] ungültige Pfade abgefangen
- [ ] Speicherfehler abgefangen
- [ ] Importfehler abgefangen
- [ ] Exportfehler abgefangen
- [ ] Neustart nach Speichern geprüft

## 4. Datensicherheit

- [ ] keine stille Überschreibung
- [ ] Backup oder Papierkorb bei Risiko
- [ ] Export mit sicherem Dateinamen
- [ ] Logs ohne sensible unnötige Daten
- [ ] Datenverlust-Risiken benannt

## 5. GUI/UX

- [ ] Hauptfunktion sofort erkennbar
- [ ] Buttons klar beschriftet
- [ ] Status sichtbar
- [ ] Fehlermeldungen verständlich
- [ ] Hilfetexte oder Tooltips vorhanden
- [ ] Kontraste ausreichend
- [ ] Layout nicht überladen
- [ ] Fenstergrößenänderung geprüft
- [ ] keine überlappenden Elemente
- [ ] lange Aufgaben blockieren GUI nicht

## 6. Performance

- [ ] keine unnötigen Dauerschleifen
- [ ] Startlogik schlank
- [ ] große Dateien sparsam behandelt
- [ ] lange Aufgaben ausgelagert oder abgesichert
- [ ] Logflut vermieden
- [ ] unnötige Abhängigkeiten vermieden
- [ ] Ressourcen werden freigegeben

## 7. Dokumentation

- [ ] README aktualisiert
- [ ] CHANGELOG aktualisiert
- [ ] TESTPROTOKOLL aktualisiert
- [ ] Startanleitung vorhanden
- [ ] Fehlerhilfe vorhanden
- [ ] Erweiterungshinweise vorhanden

## 8. Abschlussbericht

Abschlussbericht enthält:

- [ ] Kurzfassung
- [ ] geänderte Dateien
- [ ] neue Dateien
- [ ] umgesetzte Funktionen
- [ ] Teststatus
- [ ] bekannte Grenzen
- [ ] Risiken
- [ ] Verbesserungsvorschläge
- [ ] nächster Schritt

## 9. Finale Selbstprüfung

- [ ] Habe ich nichts Wichtiges vergessen?
- [ ] Ist die Lösung effizient?
- [ ] Ist die Lösung schnell genug?
- [ ] Ist die Qualität professionell?
- [ ] Ist die GUI modern und bedienbar?
- [ ] Ist Validierung ausreichend?
- [ ] Gibt es proaktive sinnvolle Optimierungen?
